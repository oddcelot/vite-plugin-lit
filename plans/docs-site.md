# Documentation site

The docs live in `docs/`, an Astro and Starlight workspace package published to
GitHub Pages at `https://oddcelot.github.io/vite-plugin-lit/`. The docs are
canonical and the README is a front door: pitch, install, and links into the
site. The site is organised as Start here, Guides, Concepts, Reference and
Contributing, each an autogenerated sidebar group so adding a page is adding a
file. Voice and page structure rules are in `docs/STYLE.md`.

## Principles

- **Task-first guides, then reference.** Guides answer "how do I ship a shared
  sheet to 3000 shadow roots". Reference answers "what does
  `cssSheetBuild: 'inline-raw'` do". Each reference page links back to the guide
  that motivates it.
- **A build verifies the docs.** `starlight-links-validator` fails the build on
  a dead internal link or dangling anchor, and the docs build runs on every PR
  that touches `docs/`, `README.md` or `CHANGELOG.md`. Only `main` deploys.
- **Agent-readable.** `starlight-llms-txt` emits `/llms.txt` and per-page
  markdown, because people paste the docs URL into an agent.
- **Boring infrastructure.** One workflow, GitHub Pages, no UI-framework
  integration.

## Decisions

- **The site is `docs/`, not `website/`.** It matches Astro's and GitHub's
  convention.
- **Hand-written options reference, no `starlight-typedoc`.** The public surface
  is small enough to curate, and typedoc's TypeScript peer range lagged the
  repo's TypeScript, which would have put a second TypeScript in the graph.
  Revisit if the API grows past about 15 exported symbols. For the same peer
  reason there is no `astro check` step.
- **Project page under `base: '/vite-plugin-lit'`, with the base written into
  internal links.** Astro does not prefix hrefs written in Markdown, and Astro
  7's Markdown processor takes no rehype plugins without swapping the processor
  out, which is too much machinery for the problem. A move to a custom domain is
  a find-and-replace over `docs/src/content/`, and the links validator fails the
  build on anything stale. Moved pages are mapped in `docs/redirects.mjs` and
  checked by `docs/scripts/check-redirects.mjs`.
- **Vite stays on the workspace catalog alias.** Astro builds fine under it. If
  a second real `vite` ever appears in the graph, the sanctioned fix is a
  parent-scoped override such as `'astro>vite'`, not removing the blanket
  override, because a duplicate Vite is what that override exists to prevent.
- **Deploy mirrors `ci.yaml`** (corepack, Node 26, `--frozen-lockfile`) and
  hands `docs/dist` to `actions/upload-pages-artifact` and
  `actions/deploy-pages`. `withastro/action` was rejected because it installs
  its own pnpm next to the repo's pinned pnpm 12 lockfile.
- **Brand: Lit's flame beside a text title, not the wordmark lockup.** This is a
  third-party plugin, and a Lit wordmark would imply it is Lit. The
  design-system fonts (Manrope, Roboto Mono) are pulled from Fontsource at build
  time and self-hosted, so nothing loads from a CDN at runtime.
- **The changelog page is synced from `CHANGELOG.md`** by
  `docs/scripts/sync-changelog.mjs`, which runs before dev and build. CI and the
  release workflow run `docs run sync` and `astro sync` before `vp check`,
  because the check type-checks generated, gitignored files.
- **No embedded live demos, no i18n, no versioned docs.** The playground is
  StackBlitz-ready and is linked instead of iframed, which would fight the
  `base` path and CSP. There is one `en` locale, so URLs stay unprefixed. The
  package is 0.x, so docs deploy from `main` and are not versioned by release.
  Add versioning only if a 1.0 breaks config.
- **`format` includes `mdx` but not `astro`.** oxfmt realigns tables and
  re-wraps prose in `.mdx`, but it mangles the nested-backtick inline-code form
  for css template literals, so that construct is written another way.
- **Guide `sidebar.order` values are spread out.** Starlight orders an
  autogenerated directory group by the lowest `order` among its pages, so group
  positions and page positions come from one sequence.
- **`docs/src/content/docs/contributing/design-docs.mdx` indexes these design
  docs** and links to GitHub rather than copying them.
