## Findings considered and rejected

- **Nested-paren `@customElement(...)` regex (`[^)]*`)**: the decorator's only
  real signature is `customElement(tagName: string)`; `@customElement(compose(...))`
  is not a real Lit usage. Not a real-world bug — do not add a test pinning the
  broken behavior. (Noted in plan 001's maintenance section.)
- **Interning map unbounded growth**: already documented as a known,
  bounded-by-edits, cleared-by-reload limitation in the package README
  ("Limitations" → "Interning map growth"). By design, not a finding.
- **Dev-server endpoint hardening** (SSE `Access-Control-Allow-Origin: *`
  cross-origin read at `timeline-plugin.ts:211`; missing Origin/Host guard on
  the open-in-editor / control / settings / inspect endpoints): surfaced in the
  audit but the maintainer chose to defer/discard for now. Both are dev-only.
  If revisited: the SSE `*` header is removable with near-zero risk (the panel
  is same-origin), and the endpoints can take a Host/Origin check.
