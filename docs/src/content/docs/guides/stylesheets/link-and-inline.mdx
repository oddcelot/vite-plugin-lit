You want this for component-local styles — the CSS one component owns, rather
than a utility layer many components share. Both forms here cost a component
re-render or a duplicated copy of the bytes, which is exactly the tradeoff the
[decision guide](/vite-plugin-lit/guides/stylesheets/) says to accept only for
one-off styles.

## External stylesheet via `<link>`

For a `<link rel="stylesheet">` (or `@import url()`) inside a shadow root, the
`?hmr-url` import query yields a real stylesheet URL (dev-served file; hashed
`.css` asset on build). On edit the component re-renders with a freshly
cache-busted href so the browser refetches — simpler than `urlSheet`, but it
**does** re-render.

```ts
import href from './my-element.css?hmr-url';

@customElement('my-el')
export class MyEl extends LitElement {
  override render() {
    return html`<link rel="stylesheet" href=${href} />
      <div class="card">…</div>`;
  }
}
```

`devCacheBust()` is the underlying helper if you import `?url` yourself:

```ts
import cssUrl from './my-element.css?url';
import {devCacheBust} from '@oddsquad/vite-plugin-lit/css.js';

const href = devCacheBust(cssUrl); // module scope, not inside render()
```

Call it at module scope. Inside `render()` every render would produce a new
href and refetch the stylesheet.

## Inlined

`?inline` (processed) or `?raw` (verbatim) hand back the CSS as a string to
feed `unsafeCSS` or `replaceSync`. No standalone `.css` asset — the text ships
inside the JS chunk — but no runtime fetch and no FOUC.

```ts
import cssText from './my-element.css?inline';

@customElement('my-el')
export class MyEl extends LitElement {
  static override styles = [unsafeCSS(cssText)];
}
```

Lit caches `static styles` **per component class**, so one component type
instantiated N times parses its sheet once. What multiplies is the number of
distinct component types that inline the same text — which is why this is the
wrong shape for a shared utility sheet and a fine shape for a component's own
rules.

To share one sheet without the fetch — the "inline shared module" row in the
comparison table — build the sheet once in its own module:

```ts
// utility-sheet.ts
import cssText from './utility.css?inline';

const sheet = new CSSStyleSheet();
sheet.replaceSync(cssText);
export default sheet;
```
